Product & UI guide

Who this is for

MineralOps Pipeline is a collaboration tool for mineral manufacturing project developers and plant operators. Capture improvement ideas, vote on what matters, assign ownership (team, location, lead), and track progress through analytics screening and core manufacturing phases.

Lifecycle phases

Analytics & decision

  1. Submitted — intake complete
  2. Impact Screening — rough ROI / strategic fit
  3. Data Validation — baseline KPIs & data ready

Core technical manufacturing

  1. Technical Feasibility — process / engineering path
  2. Process Efficiency — recovery, throughput, control
  3. Supply Chain Resolution — feedstock, logistics, vendors
  4. Waste & ESG Alignment — tailings, water, compliance
  5. Pilot Execution — controlled trial
  6. Scale-Up / Production — line or multi-site rollout

Closed

  1. Realized / Closed — value captured or retired

UI / UX map

  • Header — product identity, Docs, Reset demo, primary Add idea
  • KPI strip — total, open, analytics vs manufacturing mix, votes
  • Filters (dropdowns) — Phase, Category, Location, Team, Priority + search
  • Board view — kanban by phase; cards show ownership and votes
  • List view — dense table for reviews, sorted by votes
  • Idea form — required ownership fields before save
  • Detail — full narrative, edit, advance phase, delete
